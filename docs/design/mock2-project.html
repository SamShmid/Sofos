What this depicts

  1. 1B3Real breadcrumbsFull Home → Work → Product Launch → Marketing Site trail instead of one hand-rolled back link.
  2. 2B2Max-width reading surfaceDescription is capped at ~62ch instead of stretching edge-to-edge at desktop widths.
  3. 3B1Section header + count idiom"Tasks · 6" replaces the plain <h3>Tasks</h3> — every sibling section now carries the same treatment and a count.
  4. 4B1 / B2 / B6Compact views rowRoadmap + Board become one row; the Board link carries the "includes sub-projects" state B6 proposes adding.
  5. 5B1 / B2Quiet secondary panel bandNotes preview, Links, Files and Suggestions share one muted panel instead of four independent full-weight sections.

What changed here, vs the shipped ProjectPage

  • The split aside + main layout (task list first, identity second) becomes one column, identity-first — on mobile today the task wall renders above the title (bug A4); this composition can't regress that way.
  • Tasks / Sub-projects gain the section-label + count idiom; today Tasks/Notes are plain h3/h4 with no counts while Sub-projects already has one — now every section matches.
  • Links / Files / Suggestions (+ a new Notes preview) move into one quiet panel band instead of three independently-weighted full sections.
  • The in-progress chip renders the shipped task status field (todo / in progress / done, Phase 26) through the unified chip system — only due dates and priorities remain the open product decision B6 flags.
  • Move gains the icon + indentation + destination-preview treatment shown in the inset below (today: a flat unindented list, no preview).
